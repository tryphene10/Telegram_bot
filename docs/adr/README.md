# Architecture Decision Records

Nommer les decisions `NNNN-titre-court.md` et utiliser le gabarit suivant.

```markdown
# ADR NNNN - Titre

- Statut : propose | accepte | remplace
- Date : YYYY-MM-DD

## Contexte

Pourquoi une decision est necessaire.

## Decision

Choix retenu et frontieres exactes.

## Consequences

Benefices, couts, risques et travail ulterieur.
```
